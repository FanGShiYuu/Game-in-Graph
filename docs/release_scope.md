# Release scope

This is a compact pre-publication research preview. It makes the central
method flow inspectable and supports fixed-seed, short-horizon checks in three
traffic scenarios.

The release intentionally focuses on the method path and lightweight examples.
Full evaluation settings, large experiment batches, baselines, training
resources, aggregate random-seed results, and publication-grade figure scripts
are outside this version's scope. They will be organized for release after
publication.

The repository contains no solver license, credential, personal path, raw
large-scale result set, or bundled third-party simulator repository.
